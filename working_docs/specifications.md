# AI Lesson Planner
An Android app that assists Last Mile School (LMS) Teachers in creating and sharing lesson plans.

---

## MVP Features (Must-Have)

These features are essential for the Minimum Viable Product:

1. **Android-Compatible**: Mobile-first UI and architecture designed specifically to run smoothly on Android smartphones and tablets.

2. **4GB RAM Hardware Constraint**: Optimized local model execution and memory management to support low-end or budget devices commonly used by teachers in remote areas.

3. **Form or Chat Assistant Generation**: Dual-mode lesson plan creation allowing teachers to either fill out a structured generator form or chat with an offline AI assistant.

4. **Local AI Model Execution**: Fully offline operation using lightweight quantized models to support last-mile schools without internet.

5. **DepEd Lesson Exemplar Alignment**: Structural guidance and templates aligned with official DepEd Lesson Exemplars, ensuring all required competencies and ILAW formats are fully integrated.

6. **Cross-Device Import/Export**: Ability to export and import lesson plans and instructional materials via physical media like USB flash drives or IMS packages.

7. **Document Export Formats**: Support for exporting generated daily lesson logs (DLLs) and worksheets into standard printable formats including `.pdf` and `.docx` (Microsoft Word).

---

## Time-Constrained Features

These features may be added if time permits:

8. **Voice-to-Text Feature**: Audio input capability enabling teachers to dictate their lesson ideas and notes instead of typing long texts on a keyboard.

9. **IPEd/Manobo Context Toggle**: A dedicated toggle or option in the generator form that automatically prompts the AI to incorporate local indigenous contexts, tribal traditions, and culture into examples and activities.

---

## Cost-Constrained Features

These features may be added if budget allows:

10. **Offline-First Cloud Sync**: A synchronization feature allowing teachers to connect when they travel down to town to download updated curriculum databases, and rely strictly on local storage when back up in remote sitios.
